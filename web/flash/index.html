Pasang firmware kontroler 2 titik langsung dari Chrome/Edge desktop. Tanpa Arduino IDE.

  1. 01

    Cek browser & kabel

    Butuh Chrome atau Edge desktop (Web Serial) dan kabel USB data, bukan kabel cas saja. Driver CP2102/CH340 harus terpasang.

  2. 02

    Colok ESP32

    Colok ESP32 DevKit ke laptop. Kalau port tidak muncul atau upload macet di "Connecting…", tahan tombol BOOT saat menyambung.

  3. 03

    Pasang firmware

    Tekan tombol di bawah, pilih port, centang Erase untuk pemasangan pertama. Tutup serial monitor dulu kalau sedang terbuka.

    Browser ini tidak mendukung Web Serial — pakai Chrome/Edge desktop. Butuh HTTPS atau localhost.
