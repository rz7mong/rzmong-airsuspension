RZMON-G FLASH

Flash firmware kontroler 2 titik dari Chrome atau Edge. Kabel data USB, bukan kabel charge saja.

  1. Export compiled binary dari Arduino IDE.
  2. Simpan sebagai web/firmware/rzmong.ino.bin.
  3. Jalankan halaman ini lewat HTTP, lalu tekan pasang.
  4. Kalau tidak terdeteksi, tahan BOOT saat menghubungkan.

Setelah selesai, buka website kontrol dan sambungkan ke RZM-AIR.
