🆘 Lupa kode? Reset lewat tombol BOOT
  1. Modul menyala normal (jangan tahan BOOT saat menyalakan — itu mode flash).
  2. Tahan tombol BOOT (GPIO0) di papan ESP32 selama 8 detik. LED biru berkedip makin cepat, layar bulat menghitung mundur.
  3. Lepas sebelum 8 detik = batal. Setelah reset: kode akses 1234, WiFi rzmong123, PIN Bluetooth 123456.
  4. Kalibrasi sensor, preset, dan WiFi router tidak berubah. Di HP, lupakan/unpair RZM-AIR lalu pairing ulang.
🌐 REMOTE INTERNET—

Kontrol dari mana saja lewat broker MQTT TLS milikmu (mis. EMQX Cloud Serverless, kuota gratis). Modul harus tersambung ke WiFi router/hotspot. Jangan pakai broker publik/tes — siapa pun bisa melihat & mengirim pesan. Panduan: docs/REMOTE.md.
